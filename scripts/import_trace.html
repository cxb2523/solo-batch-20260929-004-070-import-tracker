如何生成追踪 JSON

在目标进程启动早期加入下面这段 meta path 钩子，退出时即得到 import_trace.json：

import atexit, collections, importlib.abc, json, threading

_hits = collections.Counter()
_lock = threading.Lock()

class _TraceFinder(importlib.abc.MetaPathFinder):
    def find_spec(self, fullname, path=None, target=None):
        with _lock:
            _hits[fullname] += 1
        return None  # 只统计，不改变导入行为

import sys
sys.meta_path.insert(0, _TraceFinder())

@atexit.register
def _dump():
    with open("import_trace.json", "w", encoding="utf-8") as fh:
        json.dump(dict(_hits), fh, indent=2, ensure_ascii=False)

支持的 JSON 格式：{"模块名": 次数}、[{"module": "...", "count": n}]，或模块名字符串数组（自动按出现次数聚合）。
